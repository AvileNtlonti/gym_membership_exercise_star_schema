# gym_membership_exercise_star_schema
1. Business Problem Definition
A gym management and fitness activity tracking environment.
The organization wants to analyze:Member engagement,trainer performance,workout effectiveness,calorie trends,membership behavior,seasonal attendance patterns.This converts raw operational data into decision-support analytics.
2.Dimensional Modeling
This is a technique used where data is organised into facts and tables using a star schema architecture
A star schema contains one central fact table and multiple surrounding dimension tables
We used sql to join all the dim_tables with the fact table illustrating our progress on the language usage
